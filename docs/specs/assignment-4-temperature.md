# Задание 4: temperature

## Цель

Выполнить один и тот же prompt с тремя настройками:

- `temperature = 0`
- `temperature = 0.7`
- `temperature = 1.2`

Сравнить ответы по:

- точности;
- креативности;
- разнообразию.

Сформулировать, для каких задач лучше подходит каждая настройка.

## Реализация в `llm_demo`

Демо отправляет один user prompt в OpenRouter три раза. Отличается только `temperature`.
Остальные параметры фиксированы:

- `model`: `inclusionai/ling-2.6-flash`
- `top_p`: `1`
- `top_k`: `80`
- `include_reasoning`: `false`
- `provider.require_parameters`: `true`
- `provider.allow_fallbacks`: `false`

Модель выбрана как бюджетная non-reasoning модель с поддержкой `temperature`, `top_p` и `top_k` в OpenRouter metadata.
Real OpenRouter check прошел через provider `Novita`.

## Проверка

Backend показывает эвристики, а не универсальный judge:

- точность: соблюдение ограничений prompt;
- креативность: качественная интерпретация выбранной температуры;
- разнообразие: отличие словаря ответа от двух других ответов.

Итоговые выводы:

- `0` лучше для стабильных, воспроизводимых и форматных задач;
- `0.7` лучше для большинства творческих задач;
- `1.2` лучше для брейншторма и необычных вариантов, но риск ошибок выше.
