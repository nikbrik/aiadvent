Сжатие истории диалога

Сценарий: в начале диалога просим запомнить BLUEFOX / Kotlin / Orbit, потом идёт шум из 54 разных учебных реплик, затем проверка памяти. Кнопка «Продолжить демо» добавит сценарий по одному сообщению в текущий чат, чтобы было видно, когда появляется summary и как меняются токены.

Как это работает

  1. В первом сообщении — три факта (кодовое слово, язык, проект)
  2. Дальше — 54 разные учебные реплики (история раздувается)
  3. Последний вопрос: «что было в первом сообщении?» — проверка recall
  4. Со сжатием: старое → резюме, в prompt только хвост + summary
